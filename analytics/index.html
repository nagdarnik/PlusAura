Ежедневная активность

Активные пользователиСессии

Что означают показатели

Активность — хотя бы одна сессия за день. Несколько сессий одного пользователя не увеличивают DAU.

WAU / MAU — уникальные пользователи за последние 7 / 30 дней на дату окончания периода.

Частота сессий — число сессий за выбранный период / активные пользователи за этот же период.

DAU / MAU — доля месячной аудитории, активная в последний день. Это не среднее значение за период.

Когорты регистрации · недельное удержание

Каждая строка — неделя регистрации. Wn — наличие сессии в дни [7n, 7n+6] после регистрации. Ячейка появляется, только когда окно наблюдения завершено для всей когорты.

Гипотеза: тренировки в первую неделю и D30 Retention

В сравнении только регистрации выбранного периода с полными 30 днями наблюдения. Группа определяется по числу завершённых тренировок в дни 0–6.

Наблюдаемая связь не доказывает причинность. Значения +35% из резюме здесь не зашиты; эффект каждый раз вычисляется по загруженным событиям.

Достижение цели · 3 завершённые тренировки

Доля активных пользователей, выполнивших ≥3 тренировок за последовательные 7-дневные окна от начала выбранного периода. Активный пользователь — хотя бы одна сессия в окне. Неполное последнее окно помечено отдельно.

Методика и загрузка данных

Данные обрабатываются локально в браузере и не отправляются на сервер. В JSON нужны обезличенные идентификаторы: имена, контакты и показатели здоровья для этих расчётов не требуются.

Формат JSON и правила проверки

observed_until — последний полностью наблюдаемый день (YYYY-MM-DD).

users: id (строка), signup (YYYY-MM-DD), segment (строка).

sessions: id, user_id, date. Одна строка — одна сессия.

workouts: id, user_id, date, duration (минуты ≥ 0), completed (boolean).

Повторные ID, неизвестные пользователи, неверные даты и события вне периода наблюдения отклоняются. Все даты — календарные дни UTC; при выгрузке приведите временные метки к этому часовому поясу.
